# JARVIS vs ULTRON — Hackathon

Sitio promocional estático y responsivo para el hackathon dirigido a estudiantes de preparatoria de Sonora.

## Archivos
- `index.html` — contenido principal
- `styles.css` — diseño responsivo
- `script.js` — menú móvil y animaciones

## Personalización rápida
### 1. Enlace de prerregistro
En `index.html` busca `id="registerLink"` y cambia `href="#"` por la URL de tu Google Form o Microsoft Form.

### 2. Fecha, sede y organizadores
La página evita inventar estos datos. Agrégalos cuando estén definidos.

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube estos archivos a la raíz.
3. Ve a **Settings > Pages**.
4. Selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda.

No usa frameworks ni dependencias externas.
